# 평가원 영어 연계 분석 · 영어 문제은행

고등학교 영어 교사용 작업 폴더입니다(2026-10-29 첫 업로드, 공개).

- `연계DB/` 평가원 모의평가·수능 영어와 EBS 교재의 연계 분석(분석표 CSV, 운영 매뉴얼, 수업자료 생성기 코드). 시작은 `연계DB/CLAUDE.md`, `연계DB/진행상황.md`.
- `문제은행/` 기출 문제은행 만들기: `프로그램/`(DB 만드는 코드), `규격/`(문항 규격 분석), `기록/`(결정 로그), `시안/`(화면 시안 원본 `시안.template.html`과 `build.py`).

## 올리지 않은 것
저작권 때문에 PC에만 둡니다: 시험지·해설·EBS 교재 원본(`기출/`, `교재/`), 문항 DB(`문제은행/DB/`, `연계DB/문항DB/`), 지문 원문이 들어간 작업 파일과 결과물(이미지, PDF, 수업용 HTML), 시안 자료(`_data.json`, `_book_sample.json`). ## 화면 시안 예시
실제 자료 대신 **가짜 지문 6개와 가짜 교재 문항 3개**로 만든 예시 시안이 들어 있습니다: `문제은행/시안/예시_화면시안.html`(브라우저로 열면 됨). 예시 글·선택지·오답률 숫자는 모두 새로 지어낸 것으로, 실제 시험·교재·EBSi 자료가 아닙니다. 다시 만들려면 `python -X utf8 문제은행/시안/예시자료/만들기.py` 다음 `python -X utf8 문제은행/시안/build.py --예시`.

실제 자료로 만드는 `build.py`(옵션 없이)는 PC에만 있는 자료가 있어야 합니다.
