# 평가원 영어 연계 분석 · 영어 문제은행

고등학교 영어 교사용 작업 폴더의 비공개 백업입니다(2026-10-29 첫 업로드).

- `연계DB/` 평가원 모의평가·수능 영어와 EBS 교재의 연계 분석(분석표 CSV, 운영 매뉴얼, 수업자료 생성기 코드). 시작은 `연계DB/CLAUDE.md`, `연계DB/진행상황.md`.
- `문제은행/` 기출 문제은행 만들기: `프로그램/`(DB 만드는 코드), `규격/`(문항 규격 분석), `기록/`(결정 로그), `시안/`(화면 시안 원본 `시안.template.html`과 `build.py`).

## 올리지 않은 것
저작권 때문에 PC에만 둡니다: 시험지·해설·EBS 교재 원본(`기출/`, `교재/`), 문항 DB(`문제은행/DB/`, `연계DB/문항DB/`), 지문 원문이 들어간 작업 파일과 결과물(이미지, PDF, 수업용 HTML), 시안 자료(`_data.json`, `_book_sample.json`). 그래서 이 저장소만으로는 시안을 다시 만들 수 없고, PC 폴더에서 `python -X utf8 문제은행/시안/build.py`를 실행해야 합니다.
