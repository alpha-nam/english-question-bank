# 인계 안내: 다른 Claude 계정에서 이어받기

2026-10-23에 제이님이 "같은 컴퓨터에서 다른 계정으로 로그인해도 작업을 바로 이어서 할 수 있게 저장해줘"라고 해서 만든 폴더입니다. 이 폴더와 `CLAUDE.md`, `진행상황.md`, `연계DB_운영매뉴얼.md`가 한 묶음입니다.

## 1. 새 계정에서 시작하는 법

1. 새 계정의 Claude 데스크톱 앱에서 `C:\Users\user\Desktop\claude\평가원 연계내역분석` 폴더를 연결합니다(접근 허용).
2. 첫 말로 이렇게 보냅니다. "연계DB\CLAUDE.md와 진행상황.md 확인해서 이어서 진행해줘."
3. Claude가 지금 상태를 두세 줄로 말하면 이어서 진행합니다. 제이님이 처음에 어떤 말로 요청했는지 궁금하면 `대화기록_2026-10-23.md`를 봅니다.

Windows 사용자 계정 자체를 바꿔서 로그인하는 경우에는 이 폴더가 `C:\Users\user\Desktop` 아래에 있어서 다른 사용자가 열 수 없습니다. 폴더 전체를 `C:\Users\Public\Documents` 같은 공용 위치로 복사해서 쓰세요. 복사한 뒤에는 5번의 확인 방법으로 빠진 파일이 없는지 봅니다.
