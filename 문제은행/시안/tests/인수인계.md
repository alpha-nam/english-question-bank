# 인수인계: 문제은행 화면 자동 시험 (cloud-e2e)

작성: 2026-11-02, 사용자(제이님) 요청으로 크레딧 문제 때문에 새 클라우드 세션으로 넘김.

## 해야 할 일(원래 요청)
`문제은행/시안/tests/` 아래 **새 파일만** 만들어 Playwright 끝까지 시험을 완성한다. `시안.template.html` 은 고치지 않는다.
- 범위: 홈 → 문제 고르기(시험·유형 고르기, 찾기, 무작위 담기) → 담기/되돌리기 → 보관함 저장·불러오기 → 인쇄 창(학생용·교사용, 쪽 넘기기) → 문항 상세 '문제/해설' 탭
- 너비 1440 / 768 / 390, 콘솔 오류 0, 가로 스크롤 없음, 키보드 이동 확인
- **해설지 인쇄는 시험하지 않는다**(제이님: QR로 제공할 것이라 필요 없음).
- 실패하는 시험은 지우지 말고 원인을 기록한다.
- tests/README.md(실행 방법, CDN 막힐 때 로컬 사본 쓰는 법)와 tests/결과.md(결과 요약)를 쓴다.
- 규칙: 저작권 자료(시험지·교재 원문, 문제은행/DB/, _data.json, _book*.json) 만들거나 올리지 않기. 예시자료/ 의 가짜 지문만 사용. 올리는 브랜치는 `cloud-e2e` 뿐(main·cloud-ui·cloud-explain 금지). 용어는 '평가원'·'교육청'. 에이전트는 1~2명, Sonnet 5.5.

## 지금까지 된 것
- 저장소 alpha-nam/english-question-bank 의 `cloud-explain` 에서 `cloud-e2e` 로 시작.
- `lib/vendor.js`: CDN(Tailwind·qrcode·Pretendard)이 막힌 환경에서 같은 버전 로컬 사본(npm: tailwindcss 3.4.17, qrcode-generator 1.4.4, pretendard 1.3.9)으로 가로채 넣는다. 화면은 가짜 주소 http://qb.test/ 로 연다(icons/ 3D 아이콘 PNG는 저장소에 없어 투명 그림으로 대신). `QB_ONLINE=1` 이면 진짜 CDN 사용.
- `lib/global-setup.js`: 시험 전에 `python build.py --예시` 와 로컬 Tailwind CSS 만들기(`QB_SKIP_BUILD=1` 이면 건너뜀).
- `lib/fixtures.js`: 콘솔 오류 수집(0개 확인), window.print 가로채기, `known()`(알려진 문제는 '예상된 실패'로 표시, `QB_STRICT=1` 이면 일반 실패), App 도우미(가로 스크롤·잘림·안쪽 가로 스크롤 재기).
- 시험 파일(specs/): 01_홈, 02_문제고르기, 03_시험지, 04_보관함, 05_인쇄, 06_문항상세, 07_화면너비. 프로젝트: `1440`(기능), `w1440`/`w768`/`w390`(화면너비).
- 1440 기능 시험은 거의 모두 통과. 알려진 실패 1건: 시험이 0회인 기관 탭(교육청)의 `aria-pressed` 가 `"0"` (true/false여야 함, allOn([])이 0을 돌려줌).
- 화면너비: 1440은 통과. 768·390에서는 가로 스크롤은 없지만(body overflow:hidden) 문제 고르기·문항 상세·인쇄 창에서 오른쪽이 창 밖으로 **잘린다**(고정 폭: 메뉴 188 + 필터 272 + 내 시험지 320, 인쇄 설정 320). 반응형 배치가 없는 것이 원인이라 `known()` 으로 '예상된 실패' 처리함. 홈·보관함은 안쪽 스크롤 상자가 옆으로 밀림(`#homeView 621>580` 등)도 기록됨.

## 아직 안 한 것
1. `npx playwright test` 를 처음부터 끝까지 한 번 돌려 전체 결과 확인(07은 마지막으로 돌렸고 모두 expected). 불안정한 시험(무작위 담기 등)은 여러 번 돌려 확인.
2. **키보드 시험 파일 추가**(08_키보드): 메뉴·체크칸·서랍·인쇄 창에서 Tab 순서, Esc, 서랍 안 초점 가두기(aria-modal), 화살표 키. (문항 상세 탭 키보드와 인쇄 쪽 넘기기는 06·05에 이미 있음)
3. 03_시험지·04_보관함·02_문제고르기를 768·390에서도 돌릴지 판단(지금 기능 시험은 1440만).
4. `README.md`(설치 `npm install`, 실행 `npx playwright test`, 환경 변수 `QB_ONLINE`·`QB_STRICT`·`QB_SKIP_BUILD`·`PYTHON`, CDN이 막힐 때 로컬 사본 쓰는 법과 버전, 스크린샷 위치)와 `결과.md`(통과/예상된 실패/발견한 화면 문제 표) 쓰기.
5. 마지막에 `cloud-e2e` 에 푸시하고 사용자에게 브랜치·요약을 한국어로 짧게 보고.

## 알아 둘 것
- 해설 탭 시험은 예시 자료에 `cm`(해설)이 없어서 브라우저 안에서만 가짜 해설을 넣어 확인한다(저장소 자료는 안 바꿈).
- 교재 문항 목록에는 상세(서랍) 열기가 없다(설계). 06 에 기록용 시험으로 넣음.
- 스크린샷은 `tests/스크린샷/`(git 제외), 결과 JSON은 `tests/test-results/결과.json`(git 제외).
- 헤드리스에서는 window.print 가 열리지 않아 호출만 가로채 쪽 수·제목을 확인한다.
