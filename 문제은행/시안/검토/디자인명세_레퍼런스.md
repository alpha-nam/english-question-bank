# 영어 문제은행 디자인 명세 (레퍼런스 종합)

출처 약어: **M3**=Material Design 3, **CB**=IBM Carbon, **HIG**=Apple HIG, **ATL**=Atlassian, **LIN**=Linear, **STR**=Stripe, **NOT**=Notion, **TDS**=토스, **NAV**=네이버, **ONE**=삼성 One UI, **KKO**=카카오. 각 규칙은 공개 지침의 취지를 이 화면에 맞게 옮긴 것이며, 수치는 이 도구용으로 확정한 값입니다(공식 문서 원문을 인용한 것이 아님. WebFetch 미사용, 알려진 공개 지침 기준).

## 0. 작업 전 선언 (Depth First)
1. 전문가라면: 색을 눈으로 고르지 않고 대비비를 계산해 고정, 같은 줄 요소의 높이·간격을 측정해 검수.
2. 원자료: WCAG 2.x 대비 공식(상대휘도), 각 시스템의 토큰 원칙, 실제 시험지 이미지 카드 스크린샷.
3. 도구: Python 대비 계산(아래 표), 브라우저에서 `getBoundingClientRect`로 정렬 측정.
4. 외부 검증: 아래 표의 계산값, 5장의 px 규칙을 스크립트로 통과, 교사 2~3인 사용 관찰.

## 1. 색 (출처: M3 색 역할·톤, CB 토큰, ATL 의미색)

**원칙**: 색조 램프는 하나(청색 계열 hue≈220, 채도 낮음)이고 강조색은 파랑 하나뿐. 의미색(성공·주의·오류·정보)은 상태 표시에만 쓰고 장식에 쓰지 않음. 상태는 색+아이콘/글자를 함께 표기(색에만 의존 금지, CB·M3). 어두운 테마는 순흑이 아닌 청회색 계열 표면을 단계별로 올리고(M3 표면 톤), 강조색은 밝게 조정.

**시험지 이미지(흰 종이) 처리**: 이미지는 두 테마 모두 **원본 흰색 그대로** 둠(색 반전·밝기 필터 금지: 문항 정확성). 대신 카드 프레임으로 어울리게 함. 밝은 테마는 카드 `surface-1`(흰색)+1px 윤곽선, 이미지는 윤곽선 안쪽 `radius-sm`. 어두운 테마는 이미지 둘레에 `--paper-frame`(`surface-3`) 여백 8px를 두어 흰 종이가 "놓인 종이"로 보이게 하고 눈부심은 `--paper-dim`(opacity .94)로 한 단계만 낮춤. 흰색 18.6:1(배경 대비)라 가독성은 최대.

## 2. 타이포그래피 (출처: TDS·NAV·ONE·KKO 한글 규칙, M3 타입 스케일, CB 생산성 스케일, HIG)

## 3. 간격·격자 (출처: M3 8dp, CB 2x 격자, TDS)

```css
:root{
  --sp-1:4px; --sp-2:8px; --sp-3:12px; --sp-4:16px; --sp-5:20px; --sp-6:24px; --sp-8:32px; --sp-10:40px; --sp-12:48px; --sp-16:64px;
  --r-sm:6px; --r-md:10px; --r-lg:14px; --r-pill:999px;
  --h-ctl-sm:32px; --h-ctl:40px; --h-ctl-lg:44px; --appbar-h:56px;
  --maxw:1440px; --gutter:24px; --col-gap:16px;
}
```

- 모든 간격·높이는 **4의 배수**, 컴포넌트 사이 간격은 **8의 배수**(4는 컴포넌트 내부 미세 조정 전용). 임의값(5, 7, 9, 15, 18px 마진) 금지.
- 레이아웃: 12열 격자, 열 간격 16px, 바깥 여백 24px(≥1280), 16px(<768). 최대 폭 1440px, 가운데 정렬. 탐색 화면은 폭을 꽉 채우되 3분할 고정 폭(아래 8장).
- 컨테이너 안쪽 여백: 카드 12px(이미지 8px 프레임), 패널 16px, 서랍·모달 24px, 표 셀 12×8.
- 컴포넌트 내부: 아이콘-글자 8px, 칩 사이 8px, 버튼 사이 8px, 섹션 사이 24~32px.
- 반응형: ≥1280 3분할, 1024~1279 오른쪽 패널을 서랍(overlay)으로, <768 한 열+하단 시트(HIG sheet).

## 4. 컴포넌트 규칙

**(a) 상단 앱바** (CB UI shell, M3 top app bar): 높이 56px, 배경 `surface-1`, 하단 1px `--line`(그림자 없음). 왼쪽 로고(24px 아이콘+Title-M 한 줄), 가운데 없음, 오른쪽 테마 전환·내 시험지(개수 배지). 좌우 패딩 24px. 앱바 안 컨트롤은 모두 높이 40px, 세로 가운데.

**(b) 탭·세그먼트** (M3 primary tabs, HIG segmented): 화면 전환은 **밑줄 탭**, 같은 데이터의 보기 전환은 **세그먼트**. 탭 높이 48px, 좌우 패딩 16px, 글자 Label(14/500), 선택 시 글자 `text-1`+하단 2px `accent` 바(탭 너비 전체), 비선택 `text-2`. 탭 간격 0(패딩으로), 모든 탭 같은 높이·같은 기준선. 세그먼트: 높이 40px, 컨테이너 `surface-2` r-md 패딩 4px, 선택 칸 `surface-1`+1px 윤곽선(`--line-strong` 사용 안 함, 선택은 글자 굵기 600+윤곽선 두 신호), 칸 최소 폭 72px, 칸 간격 0.

**(c) 카드** (M3 outlined card, ATL, STR): 배경 `surface-1`, 1px `--line`, r-md(10px), 그림자 없음. 구조 위→아래: ① **머리 영역 한 줄**(높이 32px: 왼쪽 `연도·번호`(Label), 오른쪽 상태 아이콘 1개), 줄바꿈 금지, 넘치면 말줄임 ② **이미지 영역**: 고정 비율(시험지 문항 평균에 맞춘 4:3 또는 문항별 `aspect-ratio` 고정, 카드 안 이미지 높이는 같은 행에서 동일), `object-fit:contain`, 안쪽 8px ③ **태그 줄**(높이 24px 한 줄, **최대 2개+"+n"**) ④ **하단 행동 영역**(높이 48px, 상단 1px 구분선, 왼쪽 보조 텍스트 버튼, 오른쪽 주 버튼 "담기"). 상태: 호버=윤곽선 `line-strong`(+이미지 확대 금지, 이동 금지), 선택(담김)=윤곽선 `accent` 2px+머리 영역 왼쪽 체크 아이콘+"담김" 글자(색만으로 구분하지 않음), 포커스=3.2 포커스 링. 카드 간 간격 16px(가로·세로 동일), 행 안 카드 폭 동일(`grid-template-columns:repeat(auto-fill,minmax(280px,1fr))`).

**(d) 칩·태그** (M3 assist/filter chip, ATL lozenge): 높이 24px(태그)/32px(필터 칩), 패딩 0 8px / 0 12px, r-pill 아님이면 r-sm(6px)·필터 칩만 r-pill, 글자 Caption 12/500. 색 역할은 **중립(`surface-2`+`text-2`)이 기본**, 강조(`accent-subtle`+`accent-text`)는 "선택된 필터" 하나, 의미색 배경은 상태(오류·완료)에만. 한 카드에 서로 다른 색 태그 2종 이상 금지.

**(e) 버튼** (M3, CB, TDS): 높이 40px(기본), 44px(큰 CTA·모바일), 32px(밀집 표 안). 패딩 0 16px, r-md, Label 14/500, 아이콘 20px+8px 간격. 주(Primary): `accent` 배경+`on-accent` 글자, 화면당 주 버튼 1~2개. 보조(Secondary): `surface-1`+1px `line-strong`+`text-1`. 텍스트(Ghost): 배경 없음+`accent-text`, 호버 `accent-subtle`. 위험: `err` 윤곽선·글자(채움은 확인 모달 안에서만). 상태: hover 배경 한 단계, active 두 단계, disabled=배경 `surface-2`+`text-3`(대비 면제 영역이나 글자 읽기 가능 유지)+커서 not-allowed, 로딩은 스피너+라벨 유지(너비 고정).

**(f) 사이드 패널·서랍·모달** (CB, HIG sheet, ATL): 그림자 대신 1px 윤곽선+`scrim` 오버레이. 오른쪽 패널(내 시험지) 폭 360px 고정, 서랍(문항 상세) 폭 `min(560px,100vw)`, 모달 폭 480/640px(r-lg 14px). 머리 56px(제목 Title-L+닫기 버튼 40×40 오른쪽), 본문 스크롤, 바닥 행동 줄 고정(72px, 상단 1px). 닫기: X 버튼+Esc+오버레이 클릭. 열릴 때 포커스를 제목 또는 첫 입력으로 이동, 닫으면 연 트리거로 복귀, 포커스 트랩.

**(g) 입력·선택상자** (M3 outlined field, CB): 높이 40px, 패딩 0 12px, 1px `line-strong`, r-md, 배경 `surface-1`. 라벨은 위(Label, 간격 8px) 고정(떠다니는 라벨 금지, 한글 가독). 포커스=테두리 `accent`+3.2 링. 오류=테두리 `err`+아래 메시지(아이콘+글자 12/16). 도움말 `text-3`. 선택상자는 같은 높이·화살표 20px.

**(h) 표** (CB data table, ATL): 행 높이 40px(밀집 32px), 머리 행 `surface-2`+Label 600, 셀 패딩 8×12, 구분선 1px `--line`(세로선 없음), 숫자 열 오른쪽 정렬+tabular, 텍스트 왼쪽 정렬, 호버 행 `surface-2`, 선택 행 `accent-subtle`+왼쪽 체크박스(24px 터치 영역). 머리 고정(sticky).

**(i) 빈 상태·토스트** (M3 snackbar, NOT, LIN): 빈 상태는 가운데 정렬 아이콘 32px(`text-3`)+Title-M 한 줄+Body 한 줄 설명+주 버튼 1개, 위 여백 64px. 토스트는 오른쪽 아래, 폭 320~420px, `surface-3`(어두운 테마)/`text-1` 배경(밝은 테마 반전)+`on` 글자, 4초(오류는 사용자가 닫을 때까지), `role="status"`(오류 `alert`), 동시 최대 3개, 간격 8px.

## 5. 정렬 체크리스트 (측정 가능, 브라우저 스크립트로 검수)

1. 같은 줄(같은 부모 flex/grid 행) 요소의 `height` 차 **0px**, `getBoundingClientRect().top` 차 0px(`align-items:center`일 때 중심선 차 ≤0.5px).
2. 형제 요소 사이 간격은 모두 같고 **8의 배수**(칩 8, 버튼 8, 카드 16, 섹션 24/32). 한 줄 안에서 간격이 둘 이상이면 실패.
3. 탭 줄: 모든 탭 높이 48px, 글자 기준선 동일, 선택 바 높이 2px이고 탭 하단과 맞닿음.
4. 카드 줄: 같은 행 카드의 높이·이미지 영역 높이·머리 영역(32px)·하단 영역(48px) 모두 동일, 머리/태그 줄은 한 줄(줄바꿈 0).
5. 왼쪽 선: 페이지 제목, 탭 줄 첫 요소, 첫 카드, 필터 라벨은 **같은 x좌표**(바깥 여백 24px) 시작. 아이콘만 있는 버튼도 시각 왼쪽 선을 맞출 것(패딩 보정).
6. 한 화면의 서로 다른 컨트롤 높이는 `{32,40,44,48,56}` 5종 이내. 반지름은 `{6,10,14,999}` 4종 이내. 글자 크기는 스케일 8종 이내.
7. 한 화면의 주 버튼(accent 채움) 개수 ≤2, 강조색 사용 면적 ≤화면의 10%.
8. 텍스트 줄 높이는 스케일값만, 임의 `margin` 금지(간격 토큰만 허용).

## 7. 접근성 (출처: WCAG 2.2, CB, M3, HIG)

- **포커스 링**: `:focus-visible{outline:2px solid var(--accent);outline-offset:2px;border-radius:inherit}` 이중 링은 어두운·밝은 이미지 위에서 `box-shadow:0 0 0 2px var(--surface-1),0 0 0 4px var(--accent)`. 링 대비 ≥3:1(accent 6.16/8.50 통과). `outline:none` 단독 금지. 마우스 클릭엔 링 숨김(`:focus-visible`).
- **터치 대상**: 최소 40×40px, 권장 44×44px(HIG 44pt, M3 48dp 중 최소치). 시각이 작은 아이콘은 `::after`로 클릭 영역 확장. 인접 대상 간격 ≥8px.
- **키보드**: Tab 순서=시각 순서; 카드는 하나의 포커스 정지점(카드 내부 버튼은 Tab으로 진입); `Enter`=상세 열기, `Space`=담기/빼기, `Esc`=서랍·모달 닫기, 탭은 ←→로 이동(`role="tablist"`, roving tabindex), 서랍 열림 시 포커스 트랩·닫힘 시 복귀. 건너뛰기 링크("본문으로") 제공.
- 상태 변화는 `aria-live`(담김·삭제·오류), 이미지에는 `alt="2025학년도 수능 31번 문항"` 식 서술, 확대 200%·글자 크기 200%에서 가로 스크롤 없음.

## 9. 하면 안 되는 것
- 카드·패널의 큰 그림자(`box-shadow` 블러 8px 이상), 다단 그림자, 그라디언트 배경·테두리.
- 한 화면 여러 색 태그(빨강·초록·보라·주황 혼용), 의미 없는 채도 높은 장식색.
- 불균일 간격(5·7·13px), 같은 줄 요소 높이 불일치, 카드마다 높이 다름.
- 반지름 혼용(4·8·12·16·20 섞기), 윤곽선과 그림자 동시 사용, 굵기 2px 이상 장식 테두리.
- 폰트 4종 이상, 굵기 5단계 이상, 12px 미만 글자, `text-3`를 연한 배경 위에 사용, 대문자 자간 장식.
- 한글 단어 중간 끊김(`keep-all` 누락), 한 줄 80자 넘는 본문.
- 호버 시 카드 이동·확대, 과한 이모지·아이콘 색 혼용, 아이콘만으로 의미 전달.
- 흰 시험지 이미지에 색 반전·필터 적용(문항 왜곡), 어두운 테마에서 순흑 `#000`+순백 `#FFF` 글자 조합.
- 주 버튼 3개 이상, 모달 위 모달, 자동 사라지는 오류 토스트.
