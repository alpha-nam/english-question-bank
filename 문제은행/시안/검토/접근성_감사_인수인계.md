# 접근성 감사 인수인계 (2026-11-02 갱신)

브랜치: `cloud-a11y` (cloud-explain f1467f2에서 갈라짐). **감사 보고서와 함께 코드 수정도 이 브랜치에 들어 있다.** 이 작업은 `연계DB/`(평가원 연계 분석)와 별개의 문제은행 시안 작업이다.

## 사용 환경 (사용자 확인)
컴퓨터 브라우저에서만 쓴다. 휴대폰·태블릿은 쓰지 않는다. 우선순위는 1440·1024·200% 확대다. 390·768 결과는 참고용.

## 끝낸 것
- 보고서 `접근성_감사_클라우드.md`: 장면 8개 × 너비 4개 표(고치기 전 기준), '수정 결과' 표, '추가로 확인한 것' 표, 확인한 것/못한 것.
- 코드 수정 (`문제은행/시안/시안.template.html`, 빌드 결과 `예시_화면시안.html`):
  - 닫힌 서랍 `inert`, 서랍·인쇄 창 포커스 가두기(Tab/Shift+Tab 순환)
  - 내 시험지 ▲▼✕ 40px·대비·이름에 문항 포함, 닫기 버튼 40px
  - 1100px 이하 한 단 배치, 768 이하 홈·보관함·인쇄 창 재배치, 390 넘침 해소
  - 글자 15px 이상, 버튼 40px(모바일 44px), 옅은 글자색 진하게
  - 건너뛰기 링크 2개(목록으로, 목록 건너뛰고 내 시험지로), 화면 전환 뒤 포커스 이동
  - 시험 선택 패널 포커스·Esc, 문제/해설 탭 roving tabindex, 토스트 위치
  - 고대비(`forced-colors`)에서 막대·선택 상태 보이게
- 확인 결과(Playwright, 1440): 대비 미달 0, 15px 미만 0, 화면 잘림 0. 200% 확대에서 가로 스크롤 없음. 606문항 목록도 오류 없음.
- 스크린샷 `스크린샷/클라우드/`(가짜 지문만, `.gitignore`가 png를 막아서 `git add -f`), 점검 스크립트 `클라우드_감사도구/`(h.js 가로채기, checks.js, run.js, kb.js, result.json).

## 일부러 남긴 것
- 표 체크박스 24px (WCAG 2.5.8 최소는 넘고 정책 40px는 못 미침. 키우려면 표 셀 구조를 바꿔야 함)
- 오답률 막대 버튼 폭 21~30px(좁은 화면, 같은 동작의 표 행이 있음)
- 어두운 모드: 아직 없음. 필요하면 새 기능으로 따로
- 쪽 나누기: 실제 DB 문항 수를 본 뒤 결정

## 이어서 할 것 (로컬에서)
1. **PC의 실제 Chrome으로 `예시_화면시안.html` 열어 보기.** 클라우드에서는 CDN(tailwind, cdnjs, jsdelivr)이 막혀 npm 대체본으로 측정했고, 아이콘 png(`icons/`)도 없는 상태였다. 글자를 15px로 키운 뒤 줄바꿈이 어색한 곳, 1024·창을 줄인 화면, 서랍·인쇄 창 Tab 가두기를 눈으로 본다.
2. (선택) NVDA 등 화면 읽기 프로그램으로 듣기. 필요한 사용자가 있을 때만.
3. 이번 수정은 템플릿 `<style>` 끝에 덧붙인 CSS가 많다. 합치기 전에 원래 클래스에 직접 반영해 정리하면 깔끔하다(동작은 같음).
4. 합치기·PR은 사용자가 정한다. 요청 없이 만들지 않는다.

## 환경 메모
- 시안 빌드: `python 문제은행/시안/build.py --예시`
- 감사 도구 다시 돌리기: 보고서 맨 아래 '다시 돌리는 방법'. `h.js` 맨 위 `FILE` 경로를 로컬 경로로 바꾼다. PC에서 CDN이 열려 있으면 `h.js`의 가로채기 부분을 빼고 돌려도 된다.
- 클라우드에서는 `npm i tailwindcss@3.4.17 qrcode-generator@1.4.4 pretendard@1.3.9`를 받아 `tw.css`를 먼저 만들었다.
