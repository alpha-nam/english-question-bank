# 접근성 감사 인수인계 (2026-11-02)

브랜치: `cloud-a11y` (cloud-explain f1467f2에서 갈라짐). 코드는 바꾸지 않았고 보고서·스크린샷·점검 스크립트만 있다.

## 끝낸 것
- `접근성_감사_클라우드.md` 초안 완성: 장면 8개 × 너비 4개 표, 확인한 것/못한 것 구분.
- 스크린샷 37장: `스크린샷/클라우드/` (가짜 지문만. .gitignore가 png를 막아서 `git add -f`로 올림).
- 점검 스크립트: `클라우드_감사도구/` (h.js 가로채기, checks.js 측정, run.js 장면 순회, kb.js 키보드 시험, result.json 원자료).

## 이어서 할 것 (우선순위)
1. 사용자 요청 확인: 해설지 인쇄는 QR로 제공하므로 점검에서 제외(이미 반영).
2. 보고서의 '못한 것' 중 해볼 만한 것: 200% 확대·글자만 키우기·`forced-colors` 에뮬레이션, 390 너비 키보드 시험, 문항 수백 개일 때 긴 목록(예시자료는 6문항).
3. 보고서 수치 재확인: 장면별 작은 터치·15px 미만 개수는 run.js 결과(result.json) 기준.
4. 완성되면 사용자에게 한국어로 브랜치와 요약을 짧게 보고.

## 환경 메모
- 클라우드에서 cdn.tailwindcss.com·cdnjs·jsdelivr가 막혀 있다. h.js가 npm의 tailwindcss 3.4.17(미리 컴파일 tw.css)·qrcode-generator 1.4.4·pretendard 1.3.9를 route로 대신 넣는다. `npm i` 후 `npx tailwindcss -i in.css -o tw.css`로 tw.css를 먼저 만든다(경로는 h.js 맨 위 상수 확인).
- 시안 빌드: `python 문제은행/시안/build.py --예시`.
- 지킬 것: 저작권 자료(시험지·교재 원문, 문제은행/DB/, _data.json, _book*.json) 만들거나 커밋 금지. 용어는 '평가원'·'교육청'. main/cloud-ui/cloud-explain에는 푸시 금지. 에이전트 최대 1~2명, Sonnet 5.5만.
