# v7 시안을 처음 열어 본 56세 영어 교사의 소감 (3차와 비교)

(캡처 home, sheet, mine, group, request, variant, mock, hub와 모바일 home을 눈으로 봤습니다. 직접 눌러 보지는 못했습니다. 되돌리기는 화면 파일의 글귀로만 확인했습니다.)

## (1) 여섯 가지 소감

**1. 수능 시험지 몇 장을 묶어 학생 시험지로**
첫 화면 맨 위에 "1 고르기 → 2 담기 → 3 인쇄" 세 칸이 생겨서, 무엇을 하는 프로그램인지 바로 알겠습니다. 3차 때보다 훨씬 낫습니다. 파란 큰 칸 "기출문제 찾기 – 시작하기"를 누르면 될 것 같습니다. 다만 "내가 가진" 시험지 파일을 올리는 곳은 이번에도 없습니다. 이미 들어 있는 문항에서 고르는 것인지, 제 파일도 되는지는 여전히 모르겠습니다. "모의고사 만들기"는 첫 화면 아래쪽으로 밀려 있고, 들어가면 "기출에서"라는 칸이 줄줄이 나옵니다. 이전보다 설명이 한 줄 붙었지만 아직 낯섭니다.

**2. 문항 세 개 담고 순서 바꾸기**
"+ 시험지에 넣기"를 누르면 "✓ 시험지에 넣음"으로 바뀌고 카드에 파란 테두리가 생깁니다. 오른쪽 "내 시험지"에는 숫자와 목록이 생기고, 줄마다 ▲ ▼ ✕가 크게 보입니다. 3차 때 걱정하던 "어느 줄을 움직이는지"가 번호와 문항 이름이 붙어 있어 알 만합니다. 이건 확실히 좋아졌습니다.

**3. 글자 키우기**
위에 "가+" 대신 "글자 크게"라고 글로 쓴 단추가 생겼습니다. 이름을 보고 바로 알겠습니다. 이게 제일 반갑습니다. 다만 크게 하기 전의 기본 글자는 여전히 작습니다. 카드 속 설명, 왼쪽 "유형" 목록, 연계 분석의 "연계 문항 23개 · 수업자료 있음" 줄은 눈을 찡그려야 하고, 문제 미리보기는 사진처럼 작아서 "전체 보기"를 눌러야 읽힙니다.

**4. 잘못 눌렀을 때**
"비우기"는 여전히 빨간 테두리라 겁이 납니다. 화면 파일을 보니 뺄 때 "되돌리기" 글자가 잠깐 나타납니다. 5초 정도라고 합니다. 저는 5초 안에 못 누를 것 같습니다. 개별 문항은 ✕로 빼고 다시 넣으면 되니 크게 불안하진 않습니다.

**5. 헷갈린 말과 버튼**
- "주문"이 "요청"으로 바뀌고 "비용은 들지 않습니다"라고 적혀 있어 안심됩니다.
- "칠판 화면"은 "수업용 칠판 화면 열기"로 바뀌고 설명도 있습니다. 알겠습니다.
- "TOP15"는 왼쪽에 설명이 생겼지만 "EBSi 오답률 TOP15"라는 말 자체는 아직 낯섭니다. 오른쪽 "독해 0 · 듣기 0 · 오답률 TOP15 0"도 무슨 숫자인지 설명이 없습니다.
- "소재 연계", "오답 5위"는 그대로입니다.
- "변형 문제 요청" 창의 "바꾸는 정도 / 지문 그대로 / 목표 난이도"는 처음 보면 어렵습니다. 그래도 "한 번에 요청하기"와 단계 안내(1단계 어떤 유형으로 바꿀까요?)는 따라갈 만합니다.
- 해 모양 단추는 여전히 이름이 없습니다.

**6. 믿음이 가는가**
첫 화면이 정리되어 있고, 진짜 시험지 모양이 나오고, 설명 글이 친절해져서 3차보다 믿음이 갑니다. 다만 연계 분석 화면은 8회 중 6회가 "준비 중"이라 덜 만든 느낌이 그대로입니다. 위 메뉴 "연계 분석"과 "EBS 교재 문항"의 차이도 모르겠습니다.

## (3) 가장 고쳤으면 하는 것 세 가지

1. **"내 파일로 시험지 만들기"를 분명히 해 주세요.** 첫 화면에 "내가 가진 시험지를 올려서 쓸 수 있나요? 예/아니오"를 한 줄로 알려 주세요. 안 되면 "이미 들어 있는 3,105문항에서 고릅니다"라고 적어 주세요. "모의고사 만들기"도 위쪽 큰 칸으로 올려 주세요.
2. **처음 글자를 지금보다 크게 시작해 주세요.** 카드 속 작은 안내 글, 왼쪽 유형 목록, 문제 미리보기를 키워 주세요. "글자 크게"를 눌러 본 적 없는 사람도 읽을 수 있어야 합니다.
3. **"되돌리기"를 오래 보이게 해 주세요.** 비우기나 뺀 뒤 "방금 한 것 되돌리기"를 5초가 아니라 화면에 계속 두거나, "비우기"를 누르면 "정말 비울까요?"를 먼저 물어 주세요. "TOP15"와 "독해 0 · 듣기 0"에도 한 줄 풀이를 붙여 주세요.
