## (4) 개선 레이아웃

카드(높이 고정 약 330px, 머리 44 + 미리보기 224 + 하단 44 + 여백 18):
```
┌────────────────────────────────────┐
│ 18  [목적]            [TOP15] [연계] │  머리 44px: 번호 18px bold, 유형=회색 태그
├────────────────────────────────────┤
│  (시험지 이미지, 위부터, 4:3)        │
│                          ⤢ 전체 보기│  fade 56px
├────────────────────────────────────┤
│ [  + 담기  ] [ 자세히 ] [ 변형 ]    │  36px, 담기 1.4배, 나머지 보조
└────────────────────────────────────┘
```
태그 규칙: 유형=회색 알약, 연계=초록 알약(교재 이름 한 단어), TOP15·오답률=분홍 알약. 한 카드에 태그는 최대 3개이고 오른쪽에 모음.

## (5) 잘 된 점

1. 칠판 테마 변수(`--bg #14241f`, `--paper #21433a`, `--exam/--book/--top`)가 수업자료와 같아 두 제품이 한 가족으로 보임. 장식 없이 절제됨.
2. 파랑=기출/선택, 초록=교재·연계 분석, 분홍=TOP15·오답률로 색의 의미가 서로 안 겹침(교재 화면 `book`에서 초록 쓰임이 일관됨).
3. 모의고사 자리표(mock)는 숫자 막대 + 연계 방식 글자로 정보 밀도와 읽기 쉬움이 좋음. 변형 만들기(variant)는 ①②③ 단계 구조가 명확함.

## (6) 가장 먼저 고칠 5개

1. 모바일 레이아웃 붕괴(#4): 접근 불가 수준.
2. 카드 머리 정리와 시험 이름 반복 제거 + 높이 고정(#1).
3. 시험지 미리보기 잘림 처리(#2).

5. 첫 화면 위계(큰 카드 1장 + 이어 하기)(#3).

## 테마 대안

본 근거: 캡처에서 시험지 이미지는 `#fafaf8` 흰 종이이고 칠판 배경(`#14241f`) 위에서 카드 안의 가장 밝은 면이 되어 시선을 독점한다. 인쇄 미리보기·PDF 결과물도 흰 종이다. 아래 대비·피로 평가는 색 값에서 추정한 것이며 실사용 테스트는 하지 않았다.

### 후보 A: 밝은 종이 테마 (도구 화면 기본)

```css
:root{
 --bg:#f2f0ea; --paper:#ffffff; --paper-2:#f7f5ef;
 --ink:#1d2623; --sub:#5b6a63;
 --line:rgba(29,38,35,.14); --line-strong:rgba(29,38,35,.32);
 --exam:#1f6fb5; --exam-bg:rgba(31,111,181,.10);
 --book:#2f7d3a; --book-bg:rgba(47,125,58,.10);
 --top:#c23a62;  --top-bg:rgba(194,58,98,.10);
 --felt:#ffe266; --mark:rgba(255,226,102,.6);
 --danger:#b5471d; --danger-bg:rgba(181,71,29,.10);
 --hover:rgba(29,38,35,.05);
 --disabled-fg:rgba(29,38,35,.4); --disabled-bg:rgba(29,38,35,.05);
 color-scheme:light;
}
```
장점
- 시험지 이미지(흰 종이)가 카드 배경과 같은 면이 되어 이미지가 "튀지 않고" 잘림 문제(#2)도 덜 눈에 띔. 이미지 둘레 흰 여백이 카드 여백처럼 읽힘.
- 인쇄 미리보기·PDF와 화면이 같은 톤이라 "보이는 대로 인쇄된다"는 일관성이 가장 높음.
- 본문 대비는 `--ink` 대 `--paper`가 매우 높음(약 15:1로 추정). 12~13px 보조글자도 `--sub #5b6a63`이 흰 바탕에서 5:1 이상으로 읽힘.
단점
- 하루 몇 시간 쓰면 밝은 화면 피로가 있을 수 있음. 완화책: 순백 대신 `--bg:#f2f0ea` 바탕과 `--paper:#fff` 카드의 2단 구성, 밝기 낮춘 `#faf9f5` 선택지.
- 수업자료(칠판)와 시각적으로 갈라짐. 다만 수업 화면은 교실 프로젝터용, 프로그램은 책상 작업용으로 목적이 다르다.
- 파랑·초록·분홍을 어두운 값으로 다시 잡아야 하고, 형광 노랑은 흰 바탕에서 효과가 약함.

```css
 --disabled-fg:rgba(236,235,230,.42); --disabled-bg:rgba(236,235,230,.06);
 color-scheme:dark;
}
```
장점
- 저조도 환경(저녁·야간 작업)에서 눈이 편하고, 칠판 테마의 색 역할(파랑/초록/분홍/노랑)을 거의 그대로 가져와 수업자료와도 같은 계열로 보임.
- 초록 틴트가 빠져 칠판 느낌이 줄고 "도구" 인상이 강해짐. 녹색 배경이 이미지의 흰색과 만들던 색 충돌이 사라짐.
단점
- 시험지 이미지(흰 종이)가 어두운 카드 안에서 가장 밝은 면이 되어 눈부심·시선 독점이 남음. 25문항 격자에서는 흰 직사각형 덩어리가 반복됨.
- 인쇄 미리보기·PDF는 흰 종이라 화면과 결과물의 톤 불일치가 그대로 있음.
- 어두운 테마에서 영어 세리프 본문은 획이 가늘어 보일 수 있음(`font-weight:450` 이상 권장).

### 추천: 후보 A(밝은 종이)를 기본으로, B는 선택 사항(어두운 모드)

이유
1. 이 도구의 중심 콘텐츠가 흰 종이 시험지(이미지·미리보기·PDF)다. 밝은 바탕이면 이미지, 미리보기, 인쇄물이 한 톤이라 가장 일관되고, 현재 시안의 가장 큰 시각 문제(흰 이미지가 어두운 칠판 위에서 깨져 보임)가 구조적으로 해소됨.
2. 정보 밀도가 높은 목록·표 화면(필터 25행, 자리표 표, 카드 격자)은 밝은 바탕에서 보조글자 가독성이 더 안전함.
3. 피로 문제는 `--bg`(회백)와 `--paper`(흰)의 2단 구성과 B 테마 전환 스위치(`prefers-color-scheme`와 수동 토글)로 흡수 가능. 토큰이 이미 변수화되어 있어 전환 비용이 작음.
4. 수업용 칠판 화면은 그대로 두고 프로그램은 별개 제품 인상으로 가는 편이 "교실 화면 vs 책상 도구"의 구분에도 맞음. 단, 연계 분석 화면으로 넘어갈 때 칠판 테마로 바뀌는 경계는 의도된 전환으로 보이게 처리 필요.
