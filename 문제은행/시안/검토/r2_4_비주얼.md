## (5) '대기업 제품 같은 느낌' 7/10

가장 큰 격차 3개
1. 시험지 미리보기 처리(#2, #9, #14): 카드마다 잘림·회색 띠·빈 공간이 달라 카드가 균질하지 않다. 대기업 제품은 이미지 영역을 고정 비율로 맞춘다.
2. 컨트롤의 마감(#6, #11, #12): native select, 상시 두꺼운 링, 두 계열 아이콘이 "브라우저 기본값" 느낌을 남긴다.
3. 첫 화면과 화면 간 연속성(#7, #8, #3): 대표 카드의 빈 공간, 좌측선 변동, 모바일 메뉴 부재가 제품 전체의 일관된 틀을 약하게 한다.

## (6) 가장 먼저 고칠 3개

1. 미리보기 규격 통일(#2, #9): 고정 비율, 위 정렬, 회색 띠 제거, 어두운 테마 프레임 8px.
2. group 서랍의 `<u>` 태그 노출(#1)과 모바일 메뉴 복구(#3): 표시 오류와 이동 불가.
3. 컨트롤 마감 일괄(#4, #6, #10, #11, #12): select 화살표, 버튼 폭 고정, 위험색, 모달 링, 아이콘 통일.

## 잘 된 점

- 밝은 종이 테마 전환으로 v5의 흰 이미지 충돌이 해소됨. 파랑·초록·분홍 역할 분담이 일관.
- 감사 도구 수치(정렬 실패 0, 격자 이탈 0, 대비 최소 5.4)가 실제 캡처와 대체로 일치. 서랍·변형 창 하단 행동 줄이 깔끔.
