# 영어 문제은행 시안 v5 — 정보 구조·직관성 점검 (r1_3)

본 것: 데스크톱 캡처 home, mine, variant, book, mock, request, drawer, hub, 모바일 sheet, 그리고 make_mockup_v5.py 전체 코드. (group, drawer_img, 모바일 home·drawer는 코드로만 확인)

## (1) 점수

| 항목 | 점수 | 한 줄 근거 |
|---|---|---|
| 첫 화면 | 7 | "무엇을 하시겠어요?"와 카드 4개로 단순하다. 다만 4개가 같은 크기·같은 무게라 시작점이 안 보이고, "연계 분석"·"모의고사"는 앞 두 개와 성격이 다르다. |
| 내비게이션 | 4 | 첫 화면으로 돌아가는 길이 로고 클릭뿐(코드상 `home(true)`, 눈에 띄는 단서 없음). "연계 분석"·"모의고사"는 기출 화면 위 팝업으로 뜨고 뒤 화면이 비친다. 교재 화면에서는 독해/듣기·시험 선택이 그대로 남는다. |

| 전체 | 5 | 뼈대(고르기→담기→내 시험지)는 맞다. 길 잃음, 용어, 한 화면에 몰린 설정이 문제다. |

## (4) 이상적인 화면 흐름

```
[처음]  ┌──────────────────────────────────────────────┐
        │  영어 문제은행    처음이세요? → 기출 한 문항 담아 보기 │
        │  ┌─ 기출문제 ─┐ ┌─ EBS 교재 문항 ─┐              │
        │  └───────────┘ └────────────────┘              │
        │  ┌─ 시험지·모의고사 만들기 ┐ ┌─ 연계 분석 ┐        │
        └──────────────────────────────────────────────┘
              │
[고르기] ‹ 처음 │ 기출문제 › 2026년 9월 › 독해      [ 독해 | 듣기 ]
        ┌ 시험 ▾ ┐ ┌ 문항 카드(번호·유형·TOP15·연계) ┐ ┌ 내 시험지 ┐
        │ 유형    │ │ [시험지에 넣기] [원본·분석 보기]  │ │ 목록(순서) │
        │(번호순) │ │ [문제 바꾸기]                  │ │ [인쇄/PDF] │
        └────────┘ └─────────────────────────────┘ │ 설정 ▾(접힘)│
              │                                    └────────────┘
[바꾸기] 문제 바꾸기 (한 번에 질문 하나)  ● 1 유형 ─ 2 정도 ─ 3 목표      기본값 선택됨
              │
[주문서] 선택한 문항 N개 · 전체 적용 줄 · [한 번에 만들기]
              │
[검토]  원본 | 변형 나란히 → [이대로 시험지에] [고치기]
```

핵심은 "고르기→넣기→인쇄"가 한 화면에서 끝나고, 변형은 같은 화면 위의 한 단계 화면(모달 아님)으로 열리며, 연계 분석·모의고사는 별도 화면이라는 점이다.

## (5) 잘 된 점

1. **한 화면 흐름이 단순하다.** 왼쪽 고르기 → 가운데 시험지 이미지 → 오른쪽 담기라는 뼈대가 교사가 종이 시험지를 다루는 순서와 같다. 문항을 글자가 아닌 원본 시험지 이미지로 보여 주는 것이 가장 직관적이다.
2. **빈 상태와 설명문이 있다.** "카드의 + 담기를 누르면 여기에 쌓입니다"(mine)와 TOP15 정의문, "목표 난이도는 실제 난이도가 아님" 설명처럼 짧은 안내가 곳곳에 있다. 낯선 개념을 풀어 쓰려는 방향이 맞다.
3. **상세 창에서 기출 → 연계 근거 → 칠판 화면으로 이어진다.** 교재 쪽수·연계 근거·바뀐 점이 한곳에 있어 "왜 연계인가"를 바로 설명할 수 있고, 난이도 등급 대신 EBSi 오답률 순위와 선택지별 비율 막대만 보여 준다는 결정이 일관된다.

## (6) 가장 먼저 고칠 5개

1. **#1·#2 길 찾기:** "‹ 처음" 버튼 + 위치 표시, 연계 분석·모의고사를 모달이 아닌 별도 화면으로.
2. **#3 변형 창:** 질문 한 번에 하나, 기본값 미리 선택, "준비 중" 칸 숨김.
3. **#4 내 시험지:** 담은 목록과 인쇄 설정을 분리(설정은 접힘), "인쇄 / PDF"만 강조.
4. **#5·#6 카드 머리와 유형 순서:** 카드 머리 태그 3개 이하(번호·유형·오답률), 연계는 배지로, 시험 선택 시 유형을 번호순으로.
5. **#7 교재 화면 전용 패널:** 책·강·구분 고르기를 만들고 기출용 필터(시험·TOP15·독해/듣기)는 숨김.

## (8) 수학 '연계 출제 스튜디오'와 비교

(코드·캡처로 직접 본 것이 아니라 질문에 적힌 설명만 근거.)

| | 수학 스튜디오(설명 기준) | 영어 시안 v5 |
|---|---|---|
| 첫 화면 | 큰 버튼 3개 → 처음 쓰는 사람에게 확실한 시작점 | 같은 크기 카드 4개 → 선택 기준이 없다 |
| 고르는 방법 | 책·과목·단원 계층 → 교사의 기존 머릿속 순서 | 시험 선택 + 유형 필터 + 검색 → 탐색 자유도는 높지만 설정이 많다 |
| 작업 흐름 | 요청서→만들기→검토 순서가 고정(길 잃기 어려움) | 요청서는 있으나 "만들기 후 검토" 화면이 아직 없다 |
| 산출물 | 학생용·교사용 PDF 두 개로 단순 | 학생 시험지/학습지/교사용 + 종이·번호·체크박스 설정이 많다 |

장점으로 가져올 것: 첫 화면의 큰 버튼 수 줄이기, 순서가 고정된 흐름, 학생용·교사용 두 가지 산출물. 영어 시안이 더 나은 점: 원본 시험지 이미지를 보며 고르는 것, 오답률·연계 근거 같은 정보 깊이. 그 깊이를 첫 화면에 보이지 않게 한 겹 뒤로 두는 것이 합칠 방향이다.

## 온보딩(7)

처음 쓰는 교사에게는 정식 안내 투어까지는 필요 없고 세 가지면 된다. (a) 첫 화면의 "처음이세요? 기출 한 문항 담아 보기" 링크, (b) 빈 "내 시험지"에 이미 있는 안내문을 3줄 단계("1 담기 → 2 순서 정하기 → 3 인쇄")로, (c) 낯선 말(TOP15, 연계 방식, 변형 정도) 옆 ⓘ 말풍선. 인쇄 설정은 기본값(A4 2단, 1번부터)으로 두고 접어 두면 안내 없이도 막히지 않는다.
