# 문제은행 시안 v7(4차) 접근성 점검 (WCAG 2.2 AA)

방법: r1_2~r3_2 보고서를 읽고 v7.template.html 코드를 확인했습니다. 로컬 서버(127.0.0.1:8765)의 v7 페이지를 브라우저에서 JS로 조작해 화면 전환 포커스, 더 보기, 서랍(열기·탭 가두기·Esc 복귀), 빈 결과 버튼을 측정했습니다. 대비는 Python으로 두 테마 토큰을 다시 계산했고, 감사기록.jsonl의 v7 기록(4차·어두움 포함)도 보았습니다. Tab 키는 실제 입력이 아니라 keydown 이벤트를 흉내 낸 시험입니다. 스크린리더 청취, 320px 재측정, 확대 시험은 하지 못했습니다.

## (3) 남은 문제

1. 2.4.3 포커스 순서(중): "더 보기"를 마지막으로 누를 때와 "필터 모두 지우기" 뒤에 포커스가 body로 이동(실측). 수정: 다시 그린 뒤 새로 생긴 첫 카드의 `.thumb`나 검색창/결과 제목(`tabindex=-1`)으로 `focus()`.
2. 3.1.2 부분 언어(중): 서랍 `qBlock`·`d.ch`의 `.ch2` 선택지(영어)에 `lang` 없음. 수정: `<span class="ch2" lang="en">`. 한국어 발문 `.stem`은 그대로 둡니다.
3. 4.1.2 이름·역할·값(중): 서랍 `role=tablist` "보기 방식". 수정: `aria-controls`와 `role=tabpanel`, 좌우 방향키·roving tabindex를 넣거나, 탭을 포기하고 `aria-pressed` 버튼 그룹으로 바꾸기.
4. 1.3.1 정보와 관계(하): 변형 요청 표(`variantDlg`, 461행) 첫 열 "회차 번호"가 `td`. 수정: `<th scope="row">`로 바꾸고 표 `caption` 추가.
5. 1.4.10 리플로(하): `.my li .g{white-space:nowrap;text-overflow:ellipsis}`, 내 시험지 목록의 긴 이름이 잘림. 수정: 줄바꿈 허용(`normal`)이나 `title` 대신 전체 이름 제공. 참고로 연계·오답 태그를 카드 밖 페이지 바탕에 쓰면 계산상 4.36~4.46으로 4.5 미달이므로 카드면 위에서만 쓸 것(현재 감사는 통과).

## (4) 대기업 제품 수준 접근성: 7.5 / 10

이유: 키보드 흐름(화면 전환 h1, 대화상자 4종의 가두기·Esc·복귀, 방향키 탭), 글자 13~17px, 대비 통과, 버튼 이름 고유성은 대기업 수준에 가깝습니다. 감점은 포커스 소실 2곳, 영어 선택지 lang, 서랍 탭 패턴 미완성, 그리고 스크린리더 실기기·고대비 모드(`forced-colors`는 코드에 없음)·200% 확대 시험이 여전히 없다는 점입니다. 위 1~3을 고치고 실기기 시험을 거치면 8.5~9점입니다.
