# 해설 탭·해설지 확인 (2026-11-02, 클라우드)

예시 화면(`python build.py --예시` → `예시_화면시안.html`)을 Playwright Chromium으로 열어 확인했다. 예시 자료에는 `cm`(해설)이 없어서, 확인할 때만 브라우저 안에서 가짜 해설을 일부·전부 넣어 보았다(저장소 자료는 바꾸지 않음).

| 확인 | 결과 |
|---|---|
| 서랍 '문제 / 해설' 탭 전환 (1440·768·390) | 됨. 해설 없으면 '해설 준비 중' 한 줄 |
| 해설지 미리보기, 해설 일부만 있음 | 1쪽, 6문항, '해설 준비 중' 4개 |
| 해설지, 해설 모두 있음 / 하나도 없음 | 둘 다 1쪽, 깨짐 없음 |
| 긴 해설로 쪽 넘기기 | 4쪽, 쪽 넘기기 2/4 이동, PDF용 묶음 4쪽 |
| 원래 번호 + 일부 문항(36, 22번) | 해설지 번호도 36, 22 순서 |
| 학생용·교사용 | 그대로(각 2쪽), 해설 블록 섞이지 않음 |
| 콘솔 오류 | 0 |
| 가로 스크롤 1440·768·390 | 없음(홈·서랍·인쇄 창) |

참고: 클라우드에서는 cdn.tailwindcss.com·cdnjs가 막혀 있어 확인할 때 같은 버전의 Tailwind CSS(3.4)와 qrcode-generator를 로컬에서 대신 넣었다. 실제 PDF 저장(window.print)은 헤드리스라 열어 보지 못했다.
