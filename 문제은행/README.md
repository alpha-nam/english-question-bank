# 문제은행 (가칭)

기출 DB, 듣기 파일, 연계 분석, 내 문항, 변형 문항을 한곳에 모아 검색·조립·인쇄·변형까지 하는 개인용 프로그램의 자리입니다. 설계는 `../연계DB/문제은행_청사진.md`, 폴더 정리안은 `../연계DB/문제은행_폴더정리안.md`에 있습니다(2026-10-28 승인).

- `DB/` 데이터. 배포용 버전에서는 통째로 뺍니다. 원본 PDF와 오디오는 `../기출`, `../교재`에 그대로 두고 여기에는 읽어서 만든 결과만 둡니다.
  - `기출/<시행연도.월>/` 문항 1개 = 파일 1개(문항 ID). 시행연도와 학년도를 모두 칸으로 둡니다.
  - `듣기/` 문항별 mp3, `교재/` 교재 문항, `연계/` 연계 분석, `내문항/` 캡처로 가져온 문항, `변형/` 만든 변형 문항, `통계/` 오답률 등
- `규격/` 유형별 출제 규격표
- `프로그램/` 화면, 검색, 조립, 인쇄, 변형 기능, 배포 빌드
- `배포/` DB를 뺀 배포 버전

기존 `../연계DB/`(수업자료 생성기, 연계 분석)는 옮기지 않고 그대로 둡니다. GitHub에는 올리지 않습니다.

## 수집 기록 (2026-10-28)
- `프로그램/수집/ebsi_download.py` + `ebsi_기출목록.json`: EBSi 기출 영어 자료(문제·정답·해설·듣기 mp3·듣기 대본)를 `../기출/<시행연도.월>/`에 받는다(2017~2026, 78회, 평가원과 교육청 학평). 이미 있던 파일은 건너뛰었고 `다운로드결과.tsv`에 결과가 있다. mp3 77개의 길이(21~27분)와 PDF 216개의 열림을 확인했다.
- `DB/통계/ebsi_오답률TOP15_원본.json`: 시험 69개(수능 홀·짝수형은 한 표를 공유)의 오답률 TOP15(문항 번호, 오답률, 배점, 정답, 선택지별 비율). 모든 행에서 정답 선택지 비율 = 100 − 오답률임을 확인했다.

## 기출 DB 변환 (2026-10-28)
- `프로그램/기출DB/build_exam.py <시험>`: 문제·해설 PDF → 문항별 JSON(`DB/기출/<시험>/<시험>-NN.json`). 글자(발문·지문·선택지, 빈칸 ＿＿＿, 밑줄 `<u>`), 표(`tables`), 정답, 유형·출제의도, 오답률(TOP15), 시험지에서 자른 문항 이미지(`이미지/Q번호.jpg`, 기존 이미지가 있는 시험은 그것을 연결).
- `verify_exam.py <시험>`: 문항 수, 선택지·발문, EBSi 오답률 TOP15 (번호·정답·배점), 기존 DB, 이미지를 대조. `run_all.py 2017 [교육청]`: 전체 실행, 결과는 `검증보고*.txt`.
- 결과(2017~2026): 평가원 29/29회, 교육청 40/40회 통과(2020.04는 쪽 크기 문제를 고쳐 글자층으로 변환). 2020.12(수능)와 2020.05는 스캔본이라 `ocr_exam.py`(한국어+영어 OCR, 데이터는 `프로그램/ocr/tessdata`)로 변환했고 45문항과 오답률 TOP15 15/15가 맞다(글자는 OCR이라 참고용, 이미지는 정확). 2020.05는 OCR이 문항 번호 8개(2,5,8,9,11,18,29,30번)를 못 읽어 그 문항은 앞 문항과 같은 이미지·글자 영역을 쓴다(JSON의 `image_shared_with`).
- 한계: 해설 글꼴이 깨진 옛 시험은 `[출제 의도]` 유형을 못 읽어 `type`이 비어 있다. 수능 짝수형은 아직 따로 변환하지 않고 홀수형만 변환한다. 도표(그래프) 문항의 수치는 글자로 없고 이미지에만 있다.
