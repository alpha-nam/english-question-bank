# 문제은행 제작 기록 (연수자료용)

2026-10-28부터 제이님(영어교사)과 함께 만든 "영어 문제은행"의 제작 과정을, 나중에 연수자료로 복기할 수 있게 기록한 폴더입니다. 이 기록은 단계가 끝날 때마다 갱신합니다.

| 파일 | 내용 |
|---|---|
| `01_결정_로그.md` | 날짜순으로 누가 무엇을 정했는지. 제이님의 지적과 그에 따른 수정, 처음 판단이 틀렸던 것 |
| `02_방법과_근거.md` | 각 단계에서 무엇을 어떻게 했고 숫자로 어떻게 확인했는지(기출 DB, 유형 분류, 난이도, 분석, 규격표) |
| `03_변형_시범_기록.md` | 변형 문항 시범(2024.06 33번)의 수정판별 비교, 검사 방법과 결과 |
| `04_연수용_교훈.md` | 변형 문항을 AI와 만들 때 조심할 점과 잘된 방법 정리 |
| `05_재현_절차.md` | 프로그램, 데이터, 실행 순서(다른 선생님이 같은 작업을 다시 하려면) |

관련 산출물의 위치(프로젝트 루트 `평가원 연계내역분석/` 기준)
- 문항 DB: `문제은행/DB/기출/<시험>/<시험>-NN.json`, 통계 원본: `문제은행/DB/통계/`
- 규격: `문제은행/규격/` (표준 유형, 발문 틀 목록, 빈칸 추론 규격표, 공식 출제방향 정리, 빈칸 분석 결과)
- 변형 시범: `문제은행/DB/변형/빈칸추론/` (문항, 규칙 검사 결과, AI 풀이 원본 `검사/`)
- 프로그램: `문제은행/프로그램/` (기출DB 변환, 수집, OCR, 변형 검사)
