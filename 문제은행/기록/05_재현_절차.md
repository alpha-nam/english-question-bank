# 재현 절차 (프로그램과 데이터)

프로젝트 루트: `평가원 연계내역분석/` (작업 본체 `문제은행/`)

## 데이터 수집
1. EBSi 기출문제 화면에서 파일 경로 목록 수집 → `문제은행/프로그램/수집/ebsi_기출목록.json`
2. `python -X utf8 -I ebsi_download.py 2017` : 문제, 정답, 해설, 듣기 mp3, 대본을 `기출/<시행연도.월>/`에 받는다(이미 있는 파일은 건너뜀, 결과는 `다운로드결과.tsv`).
3. 오답률 TOP15: EBSi 화면의 팝업을 읽어 `DB/통계/ebsi_오답률TOP15_원본.json`.
4. 메가스터디 정답률: `main_rate_ax.asp`에 시험 번호를 보내 받은 표 → `DB/통계/megastudy_정답률_영어_원본.json` (페이지의 문자 인코딩이 EUC-KR이므로 그렇게 해석해야 한글이 깨지지 않음).

## 기출 DB 변환
- `문제은행/프로그램/기출DB/build_exam.py <시험>`: 문제 PDF와 해설 PDF → 문항 JSON. `layout.py`(영역, 표, 이미지), `ocr_exam.py`(스캔본), `std_types.py`와 `apply_std_types.py`(유형과 발문 틀)
- `verify_exam.py <시험>`: 자동 검증. `run_all.py 2017 [교육청]`: 전체 실행과 `검증보고*.txt`.
- 스캔본 OCR에는 한국어 데이터가 필요하다(`프로그램/ocr/tessdata`, 공식 tessdata).

## 분석과 규격
- 빈칸 분석: `규격/빈칸분석/배정/`(번호별 4팀 배정), `규격/빈칸분석/결과/team1~4.jsonl`(문항별 분석 결과 원본)
- 산출 문서: `규격/표준유형_초안.md`, `규격/발문틀_목록.csv`, `규격/빈칸추론_규격표_초안.md`, `규격/공식_출제방향_정리.md`

## 변형과 검사
- 변형 문항: `DB/변형/빈칸추론/시범_2024.06-33.json`(현재판), `버전기록/`(이전판)
- 규칙 검사: `python -X utf8 -I 프로그램/변형/check_blank.py <문항 JSON>` → 같은 위치에 `_규칙검사.json`
- AI 검사: `DB/변형/빈칸추론/검사/`의 `문제지*_정답없음.json`을 정답 없이 각 AI에게 주고 `풀이*.json`으로 받음. 보정용 기출 12문항: `보정_문제지.json`, 실제 값 `_보정_정답_열지말것.json`.
