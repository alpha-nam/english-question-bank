# 유형 적합도 분석기 v1 역검증 결과 (2026-10-28)

표본: 평가원 기출 10개 유형 × 20지문 = 200지문, 원래 글로 되돌리고 이름을 가림. AI 판정 3회(A·B·C) 독립, 흔적을 고친 25지문은 3회 다시 판정. 판정 규칙 `프로그램/적합도/judge.py`, 원자료 `검증_v1.json`.

| 지표 | 결과 |
|---|---|
| 실제 출제 유형을 '적합'으로 봄 | 79.5% |
| 실제 출제 유형을 '적합' 또는 '조건부'로 봄 | 96.5% |
| 지문당 '적합' 유형 수 | 평균 6.7개(10개 중) |
| 추천 3개에 실제 유형이 듦(규칙) | 40.5% (무작위로 3개 고르면 30%) |
| 추천 3개에 실제 유형이 듦(AI가 바로 고름) | 34.7% (빈칸만 100%, 어법 0%) |
| 같은 지문 3회 판정이 같음 | 80.8% |

## 해석

1. **평가원 지문은 대부분 여러 유형으로 만들 수 있다.** AI가 뽑은 재료(다시 말하기, 3덩어리 분할, 삽입 후보, 요약 짝, 어법 후보)가 실제 출제 유형과 상관없이 거의 모든 지문에 있었다. 그래서 "평가원이 실제로 고른 유형"은 지문만 보고는 거의 맞힐 수 없다(추천 3개 적중 40%, 무작위 30%).
2. **그래서 이 검증은 '만들 수 있는가'(재현율)는 재지만 '좋은 추천인가'(변별)는 못 잰다.** 재현율은 96.5%로 목표(85%)를 넘었지만, 지문당 6.7개가 '적합'이라 추천으로는 쓸모가 적다.
3. **AI가 바로 고르게 하면 빈칸에 쏠린다.** 모든 지문에 빈칸을 추천하는 경향이 있어 빈칸 적중 100%·어법 0%. 흔적을 고치자 어휘 적중이 48%→10%로 떨어졌다(흔적이 답을 알려 주고 있었다는 증거).

## 다음 검증(변별을 재는 방법)

- **음성 대조군:** 이야기·실용문·도표·심경 지문(18·19·25~28·43번)을 넣어, 맞지 않는 유형을 '부적합'으로 거르는지 잰다.
- **교사 블라인드:** 제이님이 고른 지문 20개에 제이님이 먼저 유형을 고르고, 분석기 추천과 맞춰 본다.
- **만든 뒤 검사:** 추천 유형으로 실제 변형을 만들어 규격 점검 통과율과 학생 정답률로 본다.
- 규칙을 더 엄격하게 해 지문당 '적합'을 3~4개로 줄이되, 재현율이 얼마나 떨어지는지 함께 본다.
