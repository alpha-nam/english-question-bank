# 변형단계 경계 측정: 일부변형 vs 소재만

작성 2026-10-28. 행별 값, 잘라 낸 교재·시험 지문, 교재 쪽 위치(시작·끝 문구)는 같은 폴더의 `변형단계_경계측정.json`에 있습니다. 아래 숫자는 모두 그 파일에서 가져왔습니다.

## 1. 대상과 측정 범위

| 구분 | 행 수 |
|---|---|
| CSV에서 연계방식이 일부변형·소재만인 행 전체 | 150 (일부변형 48, 소재만 102) |
| 그중 읽기 문항(18번 이상) | 51 (일부변형 14, 소재만 37) |
| 듣기 교재와 연계된 읽기 문항(지시에 따라 제외) | 21 (일부변형 8, 소재만 13) |
| **측정 대상** | **30 (일부변형 6, 소재만 24)** |
| 교재 지문을 찾지 못함 | 3 (아래 3절) |
| 실제로 잰 행 | 27 (일부변형 5, 소재만 22) |
| 중복을 뺀 지문 수(2026.06 43·44·45는 한 지문) | 25 (일부변형 5, 소재만 20) |

분포는 중복을 뺀 25개 지문으로 계산했습니다.

## 2. 무엇을 어떻게 쟀나

- **(a) 내용어 비율**: 시험 지문의 내용어(세 글자 이상, 기능어 제외) 토큰 가운데, 같은 형태나 같은 어간으로 교재 지문에도 나오는 것의 비율.
- **(b) 4단어 구절 비율**: 시험 지문 단어 가운데, 교재에도 그대로 있는 4단어 이상 연속 구절에 속하는 단어의 비율(시험 지문 기준). 함께 기록한 값: 가장 길게 겹치는 연속 단어 수.
- **(c) 같은 뜻 문장 수**: 직접 눈으로 대조해 셌습니다. *strict*는 같은 명제를 말하는 문장(바꿔 쓰기 허용)이고, *partial*은 핵심 사실이나 주장은 같지만 범위·세부가 바뀐 문장입니다.
- **기준선**: 서로 연계되지 않은 짝(시험 지문 k와 다른 행의 교재 지문)으로 (a)(b)를 같은 방식으로 잰 값입니다. 우연히 겹치는 정도의 바닥값으로 씁니다.
- 지문 정리: 한글, 각주, ①~⑤, (a)~(e), `<u>` 태그, 빈칸 밑줄을 지웠습니다. 도표 문항은 시험·교재 모두 다섯 진술을 지문에 포함했습니다.

## 3. 지문을 찾지 못한 행

| 시험-문항 | 연계방식 | 이유 |
|---|---|---|
| 2024.09-27 | 일부변형 | 교재 출처가 수능완성 실전 2회 9번(듣기 담화, Campus Visit Day). 학생용 교재 텍스트에는 선택지만 있고 듣기 대본(정답과 해설)이 자료에 없어 듣기 문항으로 제외 |
| 2024.09-43~45 | 소재만 | 수능완성 실전 3회 16~17번(듣기 1담화 2문항). 대본이 없음 |
| 2024.11-27 | 소재만 | 수능완성 실전 1회 12번(듣기 짧은 대화). 대본이 없음 |

이 밖에 2024.11-43~45(일부변형)는 1강 2번만 대조했습니다. CSV 근거에 따르면 이야기의 골격은 같은 책 실전 1회 14번(듣기)에서 왔는데, 이 문항의 대본이 자료에 없기 때문입니다.

## 4. 분포 (최소 / 1사분위 / 중앙 / 3사분위 / 최대)

| 지표 | 일부변형 전체 (n=5) | 일부변형 중 도표 (n=4) | 소재만 (n=20) | 기준선, 비도표 무관 짝 (n=420) | 기준선, 도표 무관 짝 (n=12) |
|---|---|---|---|---|---|
| (a) 내용어 토큰 비율 | 0.038 / 0.622 / 0.648 / 0.661 / 0.681 | 0.622 / 0.641 / 0.655 / 0.666 / 0.681 | 0.048 / 0.104 / 0.139 / 0.176 / 0.274 | 0 / 0.028 / 0.051 / 0.078 / 0.272 | 0.056 / 0.121 / 0.201 / 0.22 / 0.339 |
| (b) 4단어 구절 비율 | 0 / 0.039 / 0.196 / 0.223 / 0.259 | 0.039 / 0.157 / 0.21 / 0.232 / 0.259 | 0 / 0 / 0 / 0 / 0.034 | 0 / 0 / 0 / 0 / 0.025 | 0 / 0.028 / 0.03 / 0.042 / 0.071 |
| 최장 연속 겹침(단어) | 2 / 5 / 5 / 9 / 12 | 5 / 5 / 7 / 9.75 / 12 | 2 / 2 / 2 / 3 / 4 | 1 / 2 / 2 / 2 / 4 | 2 / 4 / 5 / 5 / 5 |
| (c) strict | 0 / 0 / 0 / 0 / 0 | 모두 0 | 모두 0 | 해당 없음 | 해당 없음 |
| (c) partial | 0 / 1 / 1 / 2 / 2 | 1 / 1 / 1.5 / 2 / 2 | 0 / 0 / 0 / 1 / 1 | 해당 없음 | 해당 없음 |

읽는 법:
- 소재만의 (a)는 0.048~0.274로, 무관한 짝의 범위(0~0.272)와 거의 겹칩니다. 단어 수준에서 소재만 지문은 우연히 겹치는 수준을 넘지 못합니다.
- 소재만의 (b)는 20개 중 18개가 0입니다. 0이 아닌 두 개는 "to Sky National Park"(2026.06-19, 0.034)와 "nature of the industry"(2026.06-24, 0.023)입니다.
- 일부변형 도표 4개의 (a)는 0.622~0.681입니다. 도표끼리 무관한 짝의 최대값 0.339보다 크고, 소재만 최대값 0.274와는 0.35 가까이 벌어져 있습니다.
- (b)에서 겹친 도표 구절은 "spent time with friends through talking on the phone", "who read online reviews before making purchases in 2015 by product category"(12단어)처럼 교재의 도입문·진술 문구를 그대로 쓴 것입니다. 다만 2024.09-25는 "above shows the percentages of" 하나뿐이라 0.039로, 도표 기준선 안에 들어갑니다.
- strict 기준 (c)는 25개 모두 0입니다. 일부변형에서도 교재 문장을 같은 명제 그대로 옮긴 문장은 없었습니다. partial은 소재만에서도 6/20개가 1입니다(도입·결론 수준의 주장이 비슷한 경우).

## 5. 경계값 제안

이 데이터에서 두 분포를 가르는 지표는 (a)와 (b)입니다. (c) strict는 가르지 못합니다.

| 판정 | 조건(하나라도 해당) | 근거 |
|---|---|---|
| **3단계(간접연계형)** | (a) < 0.30 **그리고** (b) < 0.05 **그리고** 최장 겹침 ≤ 4단어 **그리고** (c) strict = 0 | 소재만 20개가 모두 이 안에 듦(a 최대 0.274, b 최대 0.034, 최장 4). 무관 짝 기준선 최대값(a 0.272, b 0.025, 최장 4)과 같은 수준 |
| **2단계(재구성)** | (a) ≥ 0.45 **또는** (b) ≥ 0.10 **또는** (c) strict ≥ 1 | 일부변형 도표 4개가 모두 (a) ≥ 0.622. (b) ≥ 0.10은 4개 중 3개 |
| 회색 지대 | (a) 0.30~0.45 또는 (b) 0.05~0.10 | 측정값이 하나도 없는 구간. 사람이 판정 |

- (a)의 경계 0.45는 소재만 최대값 0.274와 일부변형 최소값 0.622의 대략 중간입니다. 도표 기준선 최대값 0.339보다도 높게 잡았습니다.
- (b) 하나만으로는 경계가 되지 않습니다. 일부변형인 2024.09-25(b 0.039)가 3단계 쪽으로 떨어지기 때문에, 2단계 조건을 "또는"으로 묶었습니다.

## 6. 대표 예

**일부변형**
1. 2025.09-25(도표, 2026 수능특강 영어 176쪽 Test 1 8번): (a) 0.622, (b) 0.196, 최장 12단어, (c) 0/2. 같은 조사(2015년 제품군별 온라인 리뷰)를 성별에서 연령대로 바꿈. 도입문 문구를 거의 그대로 씀.
2. 2025.11-25(도표, 2026 수능특강 영어 55쪽 8강 4번): (a) 0.681, (b) 0.259, 최장 9단어, (c) 0/2. 같은 십 대 의사소통 조사를 성별에서 빈도 범주로 바꿈.
3. 2024.11-43~45(장문, 2025 수능완성 10쪽 1강 2번): (a) 0.038, (b) 0, 최장 2단어, (c) 0/0. 겹치는 것은 Aicken 지명과 계곡 하이킹뿐이라 수치로는 소재만과 구별되지 않습니다. CSV 바뀐점도 이 대조에 대해서는 "소재만"이라고 적어 두었습니다(실제 골격 출처는 대본이 없는 듣기 문항).

**소재만**
1. 2026.09-29(어법, 2027 독해연습 43쪽 4강 2번): 소재만 가운데 (a)가 가장 높은 0.274, (b) 0, (c) 0/1. "리더십과 공감"이라는 주제는 같지만, 교재는 공감 자체의 가치를, 시험은 직원 만족을 위한 공감을 말해 방향이 다름.
2. 2026.06-19(심경, 2027 수능특강 영어 145쪽 안내문): (a) 0.048, (b) 0.034("to Sky National Park"), (c) 0/0. 지명 하나만 가져와 안내문을 이야기로 바꿈.
3. 2024.09-22(요지, 2025 수능완성 87쪽 실전 1회 22번): (a) 0.132, (b) 0, (c) 0/0. 같은 주제(동물과 도덕성)에 반대 논지.

## 7. 한계

- **표본이 작고 치우쳐 있습니다.** 잰 일부변형 5개 중 4개가 도표이고, 나머지 1개는 출처 일부만 대조했습니다. 그래서 2단계 하한(a ≥ 0.45, b ≥ 0.10)은 **도표 문항으로만** 검증된 값이고, 산문 지문의 일부변형 경계는 이 측정으로 확인되지 않았습니다.
- 일부변형 읽기 문항 14개 가운데 8개는 듣기 교재 연계라 지시에 따라 뺐습니다. 이 8개(대본은 `수능특강 영어듣기 정답과해설.txt`에 있음)를 재면 산문형 일부변형의 경계를 확인할 수 있습니다.
- 도표는 장르 문구("The graph above shows the percentage of …") 때문에 (a)(b)가 부풀려집니다. 도표 기준선(a 최대 0.339, b 최대 0.071)과 같이 읽어야 합니다.
- 2025 수능완성 텍스트는 글자 간격이 깨져 있어, 기출 어휘 목록으로 쪼개진 단어를 이어 붙였습니다. 2025 수능특강·독해연습은 OCR본(예: 771%)입니다. (b)는 공백을 없앤 문자열로 찾아 이 영향을 줄였지만, (a)의 어간 처리는 단순 접미사 제거입니다.
- (c)는 한 사람(Claude)이 판단한 값이고 다른 평가자의 대조는 없습니다. 판단 근거는 JSON의 `c_note`에 행마다 적었습니다.
- 2026.06 43·44·45는 같은 지문이라 분포에서는 한 번만 셌습니다(JSON에는 세 행 모두 있음).
