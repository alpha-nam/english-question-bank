# 요지 파악 기출 24문항 분석 요약

대상: 2018.09~2026.09 평가원 22번 24문항(규격/대의분석/배정/요지.json). 문항별 원자료는 `결과/요지.jsonl`.
본문·선지·정답만 보고 분석했다. 오답률·해설 같은 통계 필드는 열지 않았다.

'상' 오답의 공통점:
1. 정답의 핵심어를 공유하되 한 요소만 바꾼다. 바뀌는 것은 주체, 인과 방향, 개념, 범위 가운데 하나다.
   - 주체: 2019.09-22 ① 매체→유전학자
   - 개념: 2024.11-22 ① 이해→조절, 2025.06-22 ⑤ 의미 창출→의미 왜곡, 2024.09-22 ⑤ 인간 고유·학습→개체 의사 결정
   - 결과: 2024.06-22 ⑤ 가치 형성→사회 건설
   - 방식: 2025.09-22 ③ 범위 확장→방식 변화
   - 인과 방향: 2020.06-22 ③
2. 본문과 사실상 일치하지만 요지가 아닌 세부를 쓴다. 부분 진술형으로 2019.11-22 ⑤, 2021.09-22 ②, 2022.06-22 ④, 2025.11-22 ③, 2026.06-22 ②가 있다. 수험생이 '본문에 있으니 맞다'고 판단하게 만든다.
3. 예시·실험의 구체 낱말로 처방이나 일반 명제를 만든다. 2025.06-22 ②(동전·확률), 2026.09-22 ①(좌석 배정), 2022.11-22 ⑤(전기 보조+정책), 2018.09-22 ③(쾌감 신경)이 그 예다.
4. 통념→반박 구조에서는 통념 쪽 진술(양보 부분)이 최강 오답이 된다. 2022.08-22 ④, 2019.06-22 ④가 그렇다.

'하' 오답은 대부분 '상식적이나 언급 없음'으로, 주제어만 공유하고 내용은 본문에 없다(예: 2018.09-22 ⑤, 2022.08-22 ②③, 2025.06-22 ③④). 문항마다 대체로 상 1~2, 중 2, 하 0~1개로 분포한다.

## (7) 관찰의 한계

- 표본이 24문항뿐이다. 영역 분포(사회 19)나 2026년 귀납형 2문항은 경향 신호일 뿐 규칙으로 보기 어렵다.
- 분석자 1인이 블라인드로 코딩했다. 실제 오답률과 대조하지 않았으므로 끌림 등급(상/중/하)은 추정이다. 오답 유형은 하나만 골랐기 때문에, 복합형(예: 낱말 유혹이면서 인과 왜곡)이 단순화되었다.
- 핵심 문장 위치는 '여러 곳'으로 판정한 경우가 많다(18/24). 이 때문에 위치 빈도는 (2)에서 처음 2문장·끝 2문장 기준으로 다시 셌다. 기준을 바꾸면 수치가 달라진다.
- 문장 수와 단어 수는 자동 분할한 값이다. 각주는 빼고 공백으로 나눴다. 선지 길이는 공백 포함 문자 수라서, 시험지 판면의 실제 폭과는 다를 수 있다.
- 주제 영역 분류는 주관적이다. 심리·경영·교육·보건을 모두 '사회'로 묶었다.
