# 교육부 수능 출제 방향 자료 정리 (2026-10-28)

제이님이 주신 두 자료를 읽은 결과입니다. 원문: ① 교육부 보도참고자료 "2025학년도 대학수학능력시험 영역별 출제 방향 3교시 영어"(2024.11.14), ② 교육부 즉시보도자료 "2026학년도 대학수학능력시험 출제 방향"(2025.11.13). ②에는 영역별 출제 방향(붙임 2)이 들어 있지 않아서 영어 세부는 ①에서만 나옵니다. 변형 문항 기준에 쓸 수 있는 것을 정리했습니다.

## 1. 공식 출제 원칙과 변형 문항에 주는 의미

| 공식 내용(출처) | 변형 문항에서의 규칙 |
|---|---|
| 교육과정 기본 어휘와 시험 과목 수준에서 **사용 빈도가 높은 어휘**를 사용(①) | 지문과 선택지의 어휘를 기본 어휘와 빈도 기준으로 점검한다. 고난도 어휘는 각주로 처리하거나 피한다. |
| 영어의 유창성뿐 아니라 **정확성**을 강조해 언어형식(어법)과 어휘 문항을 포함(①) | 어법과 어휘 변형은 정확성이 핵심이므로 의도하지 않은 어법 오류가 없어야 한다(문법 정합 검사). |
| 읽기는 **배경지식 및 글의 단서를 활용해 의미를 이해하는 상호작용적 독해**를 측정(①) | 정답은 글의 단서에서 이해로 도출되어야 하고, 단서 없이 상식만으로 풀리면 안 된다. |
| **내용 영역(인문, 사회, 자연, 예술, 문학 등)별로 균형** 있게 출제(①) | 변형 문항의 소재를 한 영역에 몰지 않고 균형 있게 고른다. |
| **인지적 과정 순서**로 문항 배열: 중심 내용·맥락 → 세부 내용 → 언어형식·어휘 → 빈칸 추론 → 쓰기 → 복합(①) | 모의고사 조립 기본 배열 순서로 쓴다(번호별 고정 유형과도 일치). |
| 문항 유형은 **모듈형 원칙**: 동일한 능력을 측정하는 유사 유형은 가감·교체할 수 있다(①) | 표준 유형은 해마다 바뀔 수 있다. 유형 목록을 고정된 것으로 보지 않는다. |
| 배점은 2점 35문항, 3점 10문항(①) | 3점 문항은 10개. 모의고사 조립 시 배점 구성에 쓴다. |
| EBS 연계 문항은 모두 **간접연계**: 지문의 주제, 소재, 요지 또는 자료가 유사한 다른 지문 사용(①), 2026학년도 영어 연계율 55.6%(②) | 연계형 변형은 교재 지문을 그대로 쓰지 않고 주제·소재·요지가 유사한 새 지문을 쓴다. |
| 교육과정에서 핵심적이고 기본적인 내용은 이미 출제된 내용일지라도 **문항의 형태, 발상, 접근 방식 등을 변화**시켜 출제(②) | 변형은 기출 문장을 베끼는 것이 아니라 형태와 발상을 바꾸는 것이다. |
| **사교육에서 문제풀이 기술을 익혀 반복 훈련한 학생에게 유리한 문항을 배제**하고, 공교육 과정 내용만으로 변별력을 확보(②) | 선택지 길이, 접속사, 형식적 요령으로 정답이 드러나는 문항을 금지한다. 정답은 이해로만 도출되어야 한다. |
| 적정 난이도의 문항을 고르게 출제(②) | 난이도는 3장의 정답률 기준 하·중·상 분포로 맞춘다. |

## 2. 우리 연계 분석과의 교차 확인 (외부 검증)

①의 EBS 연계 예시 4건을 우리 연계 DB(2024.11 수능)와 비교했습니다. 4건 모두 교재, 쪽, 문항 번호가 일치합니다.

| 수능 문항 | 공식 자료의 연계 교재 | 우리 분석 |
|---|---|---|
| 영어 3번 | 수능완성 영어 84쪽 실전 모의고사 1회 15번 | 일치 |
| 영어 4번 | 수능완성 영어 150쪽 실전 모의고사 5회 4번 | 일치 |
| 영어 25번 | 수능특강 영어 218쪽 Test 3회 9번 | 일치 |
| 영어 26번 | 수능완성 영어 115쪽 실전 모의고사 2회 43~45번 | 일치 |

참고: 공식 자료는 연계 방식을 모두 "간접연계"로만 부릅니다. 우리 DB의 연계 방식 이름(일부변형, 소재만, 인물만 등)은 우리가 문항을 비교해서 붙인 분류이고 공식 용어가 아닙니다.

## 3. 아직 없는 자료 (구하면 좋은 것)

- **2026학년도 수능 영역별 출제 방향 붙임 2**(영어): 이번 파일에는 일반 방향만 있고 영어 세부가 없습니다.
- **다른 연도의 영역별 출제 방향 자료**(2018~2026학년도 영어): 해마다 유형을 가감하거나 방향이 바뀐 점(예: 간접연계 전환, 빈칸 유형 변화)을 비교하면 출제 방향의 흐름을 알 수 있습니다. 같은 사이트나 평가원 자료실에 매년 공개되어 있습니다.
- 평가원이 발표한 **문항 해설 자료와 출제 경향 분석**이 있다면 함께 보면 좋습니다.
