## 2. 방법(기존과 같음)

- a, b, 최장 연속 겹침, c strict/partial의 정의와 계산 코드는 지난번 것(`scratchpad\m\measure.py`)을 그대로 썼습니다.
- 교재 쪽에는 대본의 영어 부분만 썼습니다. 화자 표시(M:/W:), [Pause] 같은 효과음 표시, 한글 번역·해설, 쪽 바닥글은 지웠습니다. 한 대본이 두 단으로 나뉜 경우(2024.06-28)와 대본 두 개를 합친 경우(2025.11-43, 2강 02번과 04번)는 구간을 이어 붙였습니다.
- 응답 문항에서 마지막 응답(정답 선택지)은 대본에 없으면 넣지 않았습니다(2024.11-27, 실전 1회 14번). 2024.11-19는 대본 끝에 Amy의 응답이 들어 있어 포함했습니다.
- OCR 띄어쓰기 오류(Y ou, w as, ha ve 등)는 지난번과 같은 기출 어휘 목록으로 이어 붙였습니다.
- 시험 실용문의 표 안 내용([ ])은 시험 JSON에 없어서 빠졌습니다(2024.06-28, 2024.11-27, 2025.09-28, 2026.06-27·28, 2026.09-27·28).
- 기준선: 보충 지문 18개를 서로 연계되지 않은 짝으로 묶어 잰 값입니다(시험 k와 다른 행의 대본, 306쌍).
- (c)도 지난번처럼 눈으로 대조했습니다. 이번에 strict 기준을 하나 더 분명히 했습니다. **문장의 주된 명제가 같아야 하고, 인물·수치·이름 같은 논항이 바뀌면 partial**입니다. 지난번 도표 도입문을 partial로 셌던 것과 같은 기준입니다.

## 5. 지난번 경계값이 산문형 일부변형까지 맞는가

- 3단계: a < 0.30 그리고 b < 0.05 그리고 최장 ≤ 4 그리고 c strict = 0
- 2단계: a ≥ 0.45 또는 b ≥ 0.10 또는 c strict ≥ 1
- 그 밖은 회색

## 6. 수정 제안

| 판정 | 조건 | 합친 43개 결과 |
|---|---|---|
| **2단계** | c strict ≥ 1, **또는** (도표이고 a ≥ 0.45 또는 b ≥ 0.10) | 일부변형 8 (도표 4 + 산문 4), 소재만 0 |
| **3단계** | c strict = 0 **그리고** c partial ≤ 1 **그리고** a < 0.30 **그리고** b < 0.05 **그리고** 최장 ≤ 4 | 소재만 28, 일부변형 1 (2024.11-43~45를 1강 2번과 잰 값) |
| 회색(사람이 판정) | 나머지. 주로 strict 0이면서 partial ≥ 2인 경우 | 일부변형 3 (2024.06-43~45, 2024.11-19, 2024.11-28), 소재만 3 (2025.09-27, 2025.09-43~45, 2026.06-28) |

바꾼 점과 근거:
1. **a·b 기준은 도표 전용으로 좁힙니다.** 산문·실용문 일부변형 8개의 a 최대는 0.362, b 최대는 0.040입니다. a ≥ 0.45, b ≥ 0.10에 닿는 경우가 없습니다.
2. **2단계의 공통 기준은 c strict ≥ 1입니다.** 일부변형 산문 4개(보조 측정 포함 5개)를 잡고, 소재만 31개 중 잘못 잡는 것은 0개입니다.
3. **3단계에 c partial ≤ 1을 더합니다.** 3단계로 떨어지던 일부변형 2개(2024.06-43~45, 2024.11-19)가 partial 2라서 회색으로 옮겨 갑니다. 대신 소재만 3개(partial 2, 2, 3)도 회색으로 옮겨 갑니다. 소재만 쪽 partial 분포는 기존 20개가 최대 1, 보충 11개가 최대 3입니다.
4. a < 0.30, b < 0.05, 최장 ≤ 4는 3단계 조건에 그대로 둡니다. 소재만 31개는 b 최대 0.034, 최장 최대 4입니다. a 최대 0.316(2025.09-43~45)은 0.30을 넘지만 partial 3이라 어차피 회색입니다.

수정한 규칙에서도 풀리지 않는 것:
- **회색 6개는 수치로 가를 수 없습니다.** 2024.11-19(일부변형: 같은 인물 Peter·Amy, "새로운 시간 보내기" 설정)와 2025.09-43~45(소재만: 같은 인물 Mike, 같은 팀 Arrows, 아빠와 본 야구 경기)는 a(0.262 vs 0.316), b(둘 다 0), strict(둘 다 0), partial(2 vs 3)로 보면 소재만 쪽이 오히려 더 가깝습니다. 듣기 대본에서 온 문항은 CSV의 일부변형·소재만 표시가 무엇에 기대는지 이 측정으로는 재현되지 않습니다. 인물·상황 틀을 가져왔는지를 따로 묻는 항목(예: "교재의 인물·고유명·상황 설정을 유지했는가")이 있어야 합니다.
- 바꾼 규칙의 핵심 조건(strict·partial)이 사람의 판단입니다. 자동 분석기로는 a·b만 계산되므로, 산문형 문항은 결국 사람이 (c)를 확인해야 합니다.
- 표본이 작습니다. 산문형 일부변형은 8개이고, 그중 7개가 듣기 대본(대화·담화)에서 온 것입니다. 읽기 교재 산문을 일부변형한 사례는 측정 대상에 없습니다.
